# Lockvyn Android 1.11.0 — Delta Update Engine

تحديث **Lockvyn Android** يضيف نظام **Differential APK Updates** لأول مرة، من غير Root أو Google Play أو حذف التطبيق.

- من **Check for app updates**: التطبيق يقارن نسخة الـAPK المثبتة بالبصمة SHA-256 للنسخ الرسمية السابقة. لو فيه Delta متوافق، يحمّل الملف الصغير بدل الـAPK الكامل.
- بيعيد تكوين APK الجديد على الهاتف بدون تعديل نسخة التطبيق المثبّتة، ويتحقق من SHA-256 الكامل وهوية الحزمة وإصدارها وشهادة التوقيع نفسها، وبعدها يفتح تثبيت Android الرسمي بموافقة المستخدم.
- لو ملف الفرق ناقص أو غير مناسب أو الجهاز عليه APK ببصمة مختلفة، البرنامج يحاول تحميل الـAPK الكامل رسميًا. أي خلل لا يمس الخزنة المحلية.
- يعرض حجم التحميل المتوقع مقابل حجم النسخة الكاملة. GitHub Actions يولّد ملفات Delta من آخر ثلاث نسخ رسمية متوافقة ويختبر إعادة بنائها قبل نشرها.

**مهم جدًا:** النسخة المثبتة قبل 1.11.0 لا تعرف تقرأ ملفات Delta؛ بالتالي **الترقية الأولى إلى 1.11.0 هتحمّل APK كامل**. بدءًا من تشغيل updater الجديد، التحديثات التالية تقدر تستعمل Delta عندما تكون النسخة الأساسية مطابقة للحزمة الرسمية وتكون هناك وفورات بالحجم.

انسخ نسخة احتياطية مشفّرة قبل الاختبار، ولا تعمل Uninstall. اختر **Check for app updates → Check for updates → Download update → Install update**. سيظل Android يطلب موافقة المستخدم على تثبيت كل تحديث. توجد نسخ احتياطية كاملة للإصدار على GitHub.
