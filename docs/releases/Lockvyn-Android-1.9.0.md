# Lockvyn 1.9.0 — Android

بعد ربط الحساب السحابي مرة واحدة، الإضافات والتعديلات المشفّرة ترفع تلقائيًا عندما يكون التطبيق مفتوحًا، ويعيد الهاتف المحاولة في الخلفية حسب جدولة Android وتوافر الشبكة. عند قفل الخزنة يمكن استقبال نسخة مشفّرة؛ تظهر التعديلات داخل الخزنة بعد فتحها. الخلفية ليست فورية دائمًا: افتح التطبيق واتصل بالإنترنت للتحديث الأسرع. إذا احتاج الحساب إلى رمز 2FA، افتح **Sync** للتحقق.

على هاتف جديد بلا خزنة، اختر **Restore from cloud · one-time pairing**، وامسح QR المعروض من **Sync** على جهازك الآخر، وسجّل بالحساب نفسه، ثم أدخل كلمة الخزنة الرئيسية على الهاتف. لا تحتاج خطوة نقل Wi-Fi الأولى عند وجود نسخة سحابية. احتفظ بنسخة احتياطية مشفّرة.

يوجد **+ Add login** ظاهر دائمًا، وتنقل مباشر **Vault / Sync / Settings**. إضافة وتعديل تسجيل الدخول في شاشة كاملة بزر حفظ ثابت؛ الاسم والموقع يعرضان خطأ بجوارهما، والخيارات الإضافية تطوى. عند النقل إلى Trash يظهر **Undo** لمدة 15 ثانية. إعداد Autofill يعرض الخطوات وحالة الخدمة.

من التطبيق المثبت افتح **Check for app updates → Check for updates → Download update → Install update**، ثم وافق على تثبيت Android. احتفظ بالتطبيق ولا تحذفه؛ اسم الحزمة وشهادة التوقيع الدائمة متواصلان مع **1.8.1**، والبيانات تبقى على الهاتف. نسخة Windows المقابلة **1.13.0**.
